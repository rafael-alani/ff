# Form & Field

Form & Field extends the official shadcn/ui website with an **Advanced** tab beside **Essentials** in its customization sidebar. Typography, spacing, surfaces, component details, and light/dark colors update the real upstream previews. Presets and source downloads include these adjustments.

Start with [FORM_FIELD.md](FORM_FIELD.md) for the studio workflows and [development setup](docs/DEVELOPMENT.md) for the pinned tools and first registry build. Once set up, run `pnpm ff:dev` and open `http://127.0.0.1:4000/create`. The [documentation map](docs/README.md) links architecture, styles, consumer integration, recovery, and upstream maintenance.

## Upstream shadcn/ui

A set of beautifully designed components that you can customize, extend, and build on. Start here then make it your own. Open Source. Open Code. **Use this to build your own component library**.
